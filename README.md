# Power BI Dashboard Projects

This repository contains seven Power BI reports built to turn datasets into interactive summaries. Together, the dashboards cover consumer complaints, healthcare, hotels, insurance, advertising, sales, and airline operations.

## Reports

| Report | Questions and views covered | Files |
| --- | --- | --- |
| [Financial Consumer Complaints](<Fiancial Complaint Dashboard/>) | How complaints vary over time, by geography, and across product or issue categories. | [Power BI report](<Fiancial Complaint Dashboard/Financial Complaints Overview.pbix>), [complaints data](<Fiancial Complaint Dashboard/Financial Consumer Complaints.csv>) |
| [Healthcare Analysis](<Health Care project/>) | A healthcare overview with demographic breakdowns for region, race, ethnicity, and preferred language. | [Power BI report](<Health Care project/Healthcare Report.pbix>), [supporting workbook](<Health Care project/Data for healthcare analyst.xlsx>) |
| [Hotel Management](<Hotel Management Report/>) | Hotel performance overview with KPI summary, geographic context, and category breakdowns. | [Power BI report](<Hotel Management Report/Hotel Report.pbix>), [hotel data](<Hotel Management Report/hotel data.csv>) |
| [Insurance Risk and Claims](<Insurance Claims Analaysis/>) | An overview of insurance claims and risk using the included insurance-policy data. | [Power BI report](<Insurance Claims Analaysis/Insurance Report.pbix>), [insurance data](<Insurance Claims Analaysis/insurance_policies_data.xlsx>) |
| [Meta Ads Performance](<Meta Ads Performance/>) | Separate Facebook and Instagram report pages built from ad, campaign, user, and event data. | [Power BI report](<Meta Ads Performance/Ads Report.pbix>), [ad events](<Meta Ads Performance/ad_events.csv>), [ads](<Meta Ads Performance/ads.csv>), [campaigns](<Meta Ads Performance/campaigns.csv>), [users](<Meta Ads Performance/users.csv>) |
| [Sales Overview](<Sales Report/>) | A sales summary with geographic and categorical views. | [Power BI report](<Sales Report/Sales Overview Report.pbix>) |
| [US Airline Analysis](<US Airline Analysis/>) | An airline overview spanning routes, airports, airline performance, fares, and geography. | [Power BI report](<US Airline Analysis/Airlines Analysis.pbix>), [routes and fares data](<US Airline Analysis/US Airline Flight Routes and Fares.csv>) |

## Open a report

Open a `.pbix` file in Power BI Desktop. Several project folders include a separate CSV or Excel source file; the Sales report folder currently contains the report only. Data refresh and source-path requirements can differ by report, so follow any prompts in Power BI Desktop and check the model before refreshing or republishing.

## Using the dashboards responsibly

The reports are portfolio examples for exploration and communication. They do not, by themselves, establish causation, forecast outcomes, or guarantee that their source data is current. Review the included data and report filters before interpreting a visual.
